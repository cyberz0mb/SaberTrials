# Saber Trials

Saber Trials is an open-source Jedi Academy multiplayer overhaul built on
OpenJK. It expands competitive saber play for newcomers and longtime players.

- **Saber combat:** Configurable Saber Trials and Original JKA rules, timed
  guards and counters, and the Orange single-saber style alongside Blue,
  Yellow and Red. Choose a ready stance and dominant hand in your profile.
- **Competition:** Duel series, single-elimination tournament brackets and
  team match statistics. Ranked menus and a local rating ledger are implemented;
  there is no live ranked ladder.
- **Multiplayer:** Worldwide server discovery, search, direct connect and Quick
  Match recommendations. The client supports text chat, optional local
  translation, controllers and an on-screen keyboard.

The current source also includes [Match Rules](docs/Match-Rules.md),
[PUG and Ladder](docs/PUG-and-Ladder.md), [multi-team TFFA](docs/TFFA-Teams.md),
and [client compatibility options](docs/Client-Compatibility.md). On Windows,
[Vulkan](docs/Vulkan-Renderer.md) is available alongside Vanilla and Rend2.

Use a legal Jedi Academy installation and keep Saber Trials separate from
`GameData/base`. Online play requires compatible client and server builds.
