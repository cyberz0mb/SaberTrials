# Saber Trials launcher icon

`SaberTrials.ico` is the official Windows launcher icon selected and supplied
by the user on November 7, 2026, as `Saber_Trials_ST_Desktop.ico`.

Preserve the supplied artwork and its seven 32-bit sizes: 16, 24, 32, 48, 64,
128 and 256 pixels. This permanent project copy is used by the **Saber Trials**
shortcuts in the project folder and on the desktop. Both open the main
`tools/launchers/SaberTrials.cmd` launcher and use its current launch settings.

Run `tools/Install-Launcher-Icon.ps1` to recreate the shortcuts after moving or
installing the project. Keep the icon with the project; shortcuts must not refer
to the original Downloads location. Existing project-folder shortcuts remain
unchanged.
