# Contributing to Saber Trials

Saber Trials is intended to be a community-friendly, GPLv2 open-source Jedi
Academy multiplayer mod. Bug fixes, accessibility work, documentation, server
administration improvements, bot behavior, spectator tools, and carefully
tested combat improvements are welcome.

## Submitting changes

Fork this repository and open a pull request against `main`. The project
owner reviews changes before they are merged. Include build instructions
and the checks you ran.

For voice chat contributions, make microphone use optional and preserve
typed chat.

## Contribution rules

- Keep all mod files isolated from Jedi Academy's `GameData/base` directory.
- Do not submit proprietary base-game data or material taken from another mod
  without clear redistribution permission.
- Preserve copyright and license headers in files derived from OpenJK or other
  projects.
- Add third-party origins to `CREDITS.txt`, including a source link, revision,
  license, and the files affected.
- Keep unrelated gameplay changes in separate commits or pull requests.
- Describe how the change was tested in Duel, FFA, TFFA, or CTF as applicable.
- Anti-cheat observations are evidence for moderator review, not automatic
  proof that a player cheated.

## Project boundaries

This repository is only for Saber Trials. Unrelated private projects, private
server credentials, moderation records, player IP addresses, and staff GUIDs
must never be committed.
