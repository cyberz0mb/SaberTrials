# Enhanced character models

Compatible clients can render a higher-detail cosmetic mesh while using the
classic model for gameplay, collision and fallback. Rend2 uses the enhanced
visuals when available. Vanilla, unsupported rigs and detached parts use the
classic geometry. An enhanced package needs a matching classic model.

See the [mesh format](Enhanced-Cosmetic-Mesh-Spec.md) for authoring details and
the [installation guide](Enhanced-Models-Installation.md) for module requirements.
