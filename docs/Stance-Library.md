# Ready stances

Select a ready stance and dominant hand from the player profile. Ready stances
change how a character holds the saber without changing its attack chain.
Single, dual and staff sabers have separate stance choices. A compatible
animation package is required, and unsupported rigs use a stock pose.

For local builds, place compatible inputs in the ignored `assets/stance-inputs/`
directory. The input hashes are pinned in the [source lock](../development-source/stances/sources.lock.json).
