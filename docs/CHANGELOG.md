# Saber Trials changelog

## November 2026

- Added Worldwide server discovery, search, direct connect and Quick Match
  recommendations based on mode, ping and population.
- Added Orange to the single-saber loadout, with a separate ready-stance
  preference. Added dominant-hand and ready-stance choices.
- Added tournament lobby and bracket controls, reconnect handling and
  substitutions. Added TFFA kills, deaths, K/D ratio and assists. Assists do
  not add team points, and teamkills do not count toward K/D or assists.
- Added match-end highlights and deciding-strike replays, with a skip option
  for each viewer.
- Redesigned Play, Profile, Controls and Setup. Added character search and
  favorites, gamepad navigation, and on-screen text entry.
- Added an emote wheel and optional offline chat translation. Text chat
  includes timestamps and controls for size and opacity.
- Added the Saber Workbench, crystal customization and blade effects.
- Added Enhanced Maps and Enhanced Models support. Added weapon DLC that
  uses stock weapon families and shared ammo, with fallback effects.
- Updated role bots to prefer character personality dialogue. Improved stance
  and handedness compatibility for custom character rigs.

## Core multiplayer changes

- Added configurable Saber Trials and Original JKA combat presets, timed
  parries and counters, and configurable Force and recovery rules.
- Added private duel challenges, Duel series, team-lock votes, match recording
  and spectator tools.
- Added permanent server staff roles and tools for server administration.
