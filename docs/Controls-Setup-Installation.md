# Controls and Setup

Use matching client, UI and cgame modules. Open **Controls** to set keyboard,
mouse and gamepad bindings, and **Setup** for display, audio and interface
settings. Named configs save settings for reuse. Confirm a new display mode
to keep it, or let the timer expire to return to the previous mode.

See the [settings catalog](Setup-Settings-Inventory.md) for available options.

Use [Block, Parry and Feint](Combat-Controls-Main.md) for combat bindings.
For gamepads, choose automatic detection and adjust menu cursor speed in
**Controls > Controller**.
